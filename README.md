# 퀵버미 급식 위젯

학교 급식(아침·점심·저녁)을 PC 바탕화면에 띄워 주는 Windows 위젯이에요.

> **지금은 베타 테스트 중이에요.** 처음 실행하면 받은 베타 코드(`XXXX-XXXX-XXXX`)를 입력해야 써요. 코드 1개는 PC 1대에서만 쓸 수 있고, 같은 PC에서는 다시 설치해도 같은 코드로 돼요. 정식 버전(v1.0.0)부터는 코드 없이 쓸 수 있어요.

## 내려받기

**[최신 버전 내려받기 →](https://github.com/LeeDoYeol/quickburmi-meal-widget-releases/releases/latest)**

아래 두 파일 중 하나만 받으면 돼요.

| 파일 | 이럴 때 |
| --- | --- |
| `QuickburmiMeal-Setup-버전.exe` | 보통은 이걸로. 실행하면 바로 설치돼요. |
| `QuickburmiMeal-버전-win-x64.zip` | 설치파일이 아예 실행되지 않을 때 (스마트 앱 컨트롤이 켜진 PC) |

나머지 파일(`latest.yml`, `update.json`, `.blockmap`, `-code.asar`)은 자동 업데이트용이라 받지 않아도 돼요.

### 설치파일로 설치

1. `QuickburmiMeal-Setup-버전.exe` 실행
2. 'Windows의 PC 보호' 창이 뜨면 **추가 정보 → 실행**
3. 아무 반응이 없거나 "스마트 앱 컨트롤이 이 앱을 차단했습니다"라고 나오면 아래 zip 방법을 쓰세요.

### zip으로 설치 (스마트 앱 컨트롤이 켜진 PC)

1. zip 파일을 마우스 오른쪽 버튼으로 눌러 **압축 풀기**
2. 풀린 폴더 안의 `QuickburmiMeal.exe` 실행 → **설치**
3. 설치가 끝나면 압축을 푼 폴더는 지워도 돼요.

## 쓰는 법

- 위젯은 바탕화면 오른쪽 위에 있어요. 다른 창에 가려져 있으면 **Win + D**(바탕화면 보기)를 누르세요.
- 작업 표시줄 오른쪽 트레이의 범고래 아이콘
  - 왼쪽 클릭: 위젯을 잠깐 앞으로 꺼내기
  - 오른쪽 클릭: 보기 방식(오늘 급식 / 다음 급식만), 창 위치(바탕화면 고정 / 항상 위 / 일반 창), 테마, 위치 잠금, 설정
- ◀ ▶ 버튼이나 날짜 위에서 마우스 휠로 날짜를 넘길 수 있어요 (오늘 앞뒤 31일).
- 위젯 오른쪽 아래 모서리를 끌면 너비가 바뀌어요. 위젯 아무 곳이나 끌면 옮겨져요.

## 업데이트

자동이에요. 새 버전을 조용히 받아 두었다가 다음에 켤 때 적용해요. 위젯에 **지금 재시작** 버튼이 보이면 눌러서 바로 적용할 수도 있어요.

## 제거

Windows **설정 → 앱 → 설치된 앱 → 퀵버미 급식 → 제거**

## 문제가 생기면

트레이 아이콘 → **설정 → 로그 폴더**에서 `main.log` 파일을 보내 주세요.
